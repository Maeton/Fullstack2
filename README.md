# Huerto Orgánico - Evaluación Parcial 1

Proyecto e-commerce desarrollado para la asignatura Desarrollo Fullstack II, basado en el caso HuertoHogar: tienda online de productos frescos y orgánicos con despacho a domicilio.

- Mateo Nogueira
- Fernanda Viveros
- Andeison Belandria

**Tecnologías Utilizadas**
* HTML5 
* CSS3 
* JavaScript Vanilla 

**Funcionalidades Implementadas**
* Catálogo de productos con imagen, precio, descripción y stock
* Buscador de productos en tiempo real
* Carrito de compras (agregar, eliminar, ver total) con persistencia en localStorage
* Formulario de registro con validaciones (nombre, email, contraseña, teléfono, dirección)
* Mapa con los puntos de despacho de HuertoHogar

**Cómo Ejecutarlo**
* 🔗 Demo en vivo: https://maeton.github.io/Fullstack2/
* Local: clona el repo y abre `index.html` en tu navegador (no requiere instalación)
