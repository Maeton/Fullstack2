# Huerto Hogar - Evaluación Parcial 2

Tienda desarrollada con React, Vite y Bootstrap para Desarrollo Fullstack II.

## Integrantes

- Mateo Nogueira
- Fernanda Viveros
- Andeison Belandria

## Funcionalidades

- Catálogo de frutas.
- Carrito con cantidades, total y almacenamiento local.
- Registro con validaciones.
- Información del emprendimiento y contacto.
- Diseño adaptable con Bootstrap.

## Ejecutar

Desde la carpeta huerto-hogar-react:

```bash
npm install
npm run dev
```

## Pruebas

```bash
npm test
```

10 pruebas con Vitest: productos, carrito y registro.
